# ⚡ MTNC AdminPanel & Tablet V3.0.0

[![FiveM](https://img.shields.io/badge/FiveM-Ready-38bdf8?style=flat-square&logo=fivem)](https://fivem.net)
[![Frameworks](https://img.shields.io/badge/Frameworks-QBCore%20|%20QBox%20|%20ESX%20|%20Standalone-10b981?style=flat-square)](https://novacore.dk)

**MTNC AdminPanel & Tablet V3** er et næste-generations FiveM administrations-økosystem med fuld paritet mellem **Web AdminPanel** (`adminpanel.novacore.dk`) og **In-Game FiveM Tablet**.

---

## 🌟 Nøglefunktioner V3
- **Dual Tablet Mode**: 👤 Spiller Profil (alle spillere) ↕ 🛡️ AdminPanel (kun staff).
- **Profil-Vælger ved Licens-Login**: Logger ind på specifikke staff-profiler med personlig **Sikkerheds PIN** (standard `1234`).
- **Database Adapters**: Automatisk tilknytning af `lb-phone`, `qb-houses`, `ox_inventory`, etc.
- **Classic Modern UI**: `#0f1115` mørkt og eksklusivt tema.
- **Server IP & Port**: Fremgår prominent i toppen af panelet og på tabletten (`127.0.0.1:30120`).
